# GameBridge for Fun

当前版本：`1.0.0-beta.1`

集成平衡挑战、角子机与骰宝的新能源体感游戏套件。游戏结果通过 macOS 本地网关转换为兼容电刺激体感设备的强度和波形指令，电脑、手机网页与 Android APK 共用同一套规则。

本项目处于早期 Beta 阶段，仅部分功能完成实机验证。由于实机测试会消耗测试人员，暂未覆盖全部设备、玩法和极端情况。请从低强度开始，避免将软件自动保护作为唯一安全措施。

## 玩法

- 手抖挑战：保持手机平稳，倾斜超出安全范围后触发输出。
- 保持角度：先校准目标姿态，持续偏离目标角度后触发输出。
- 摇骰子对决：双方各摇三颗骰子，按点数差和豹子规则结算输出次数。
- 极速角子机：三个图标同时开奖，未中奖会推高压力，压力满格后按规则结算。

玩法包含角子机、骰宝等娱乐场景，仅用于无金钱游戏体验。严禁用于赌博、押注、收费抽奖、代币兑换或任何涉及金钱与财物输赢的活动。

## 运行要求

- 一台运行 macOS 的电脑，Python 3.9 或更高版本。
- 电脑与手机连接同一个可信 Wi-Fi。
- DG-LAB 4 App 与兼容的电刺激体感设备。
- 手机浏览器，或 Android 15 及以上设备安装仓库 `APK/` 中的安装包。

普通使用不需要 Node.js、Java、Android Studio 或 `uv`。这些工具只用于继续开发和构建 Android 包。

## 启动

1. 下载完整项目并解压，不要只复制单个启动文件。
2. Mac 与手机连接同一个可信 Wi-Fi，关闭会接管局域网路由的 VPN。
3. 双击 `start.command`；首次被 macOS 拦截时，右键该文件并选择“打开”。
4. 启动器会检查 Python、依赖、网络、证书和 APK，能够自动处理的项目会在项目专用环境中完成。
5. 电脑控制台打开后，在 DG-LAB 4 App 的 Socket 控制中扫描 V4 二维码，再连接兼容设备。
6. 控制台显示设备和 App 限幅均已就绪后，再扫描游戏二维码。
7. 在游戏选择页确认一次全局波形与 A/B 通道；所有玩法共用这份设置。

首次运行时，启动器会在项目独立环境中安装唯一的 Python 通信依赖 `websockets 12.0`。此后每次启动都会检查 Python、依赖版本、运行文件、局域网、HTTPS 证书和 APK 完整性；必要检查失败时服务不会启动，终端会保留具体原因和处理方式。

完整操作、玩法参数、故障排查和实机演练见 `USER_GUIDE.md`。

## Android APK

公开安装包为 `APK/GameBridgeForFun-Android15-v1.0.0-beta.1.apk`，要求 Android 15 或更高版本。`APK/SHA256.txt` 用于核对文件完整性，安装包使用独立正式签名，不再使用 Android 调试签名。

如果手机安装过旧的调试签名包，必须先卸载旧包再安装本版本；Android 不允许不同签名直接覆盖，同步清除的本地游戏设置需要重新配置。

APK 只接受私有局域网地址、固定游戏路径、合法端口和本次服务生成的 token。APK 切入后台、锁屏、返回连接页或页面崩溃时，会断开连接并请求停止输出。

## 手机 HTTPS 证书

iPhone 浏览器的方向与动作感应权限通常需要 HTTPS。服务会在 Mac 上自动生成本地证书，但不会自动安装到手机，也不会自动取得手机信任；Android APK 不需要安装网页根证书。

证书私钥保存在 `~/Library/Application Support/GameBridge for Fun/certs/private/`，不会放进源码目录。根证书默认有效 90 天，服务器证书默认有效 7 天。

完全信任根证书会扩大手机的 HTTPS 信任范围。仅在私人设备和可信局域网中安装，核对控制台显示的 SHA-256 指纹，不得分享或上传 Mac 中的证书私钥。结束后建议关闭完全信任，长期不用时应在 `设置 > 通用 > VPN 与设备管理` 删除描述文件。

如果私钥可能泄露，应立即关闭手机上的完全信任并删除描述文件，删除 Mac 应用数据目录中的旧证书，再重新启动服务生成新证书。

## 安全要求

- 本项目会触发真实电刺激输出，不是医疗设备，也不能替代人工监护和设备 App 内的手动停止。
- 仅限能够理解风险、主动同意并能独立停止设备的成年人使用；身体状况不确定时不要使用。
- 首次连接、更换设备、更换通道或升级 App 后，从低强度、短时长、单通道开始。
- 不要跨胸放置电极，不要用于头部、颈部、破损皮肤或无法及时移除的位置。
- 不要在睡眠、饮酒、意识不清、无人看护或无法接触设备 App 停止按钮时使用。
- 开始前确认 App 的 A/B 限幅、静音、过热状态和手动停止均有效；出现异常立即在设备 App 中人工停止。

服务端会再次限制强度、时长、请求频率和并发任务。页面断开、传感器失效、输出心跳停止或程序正常退出时会请求清空 A/B，但断电、系统强制终止和硬件故障不能由软件完全覆盖。

## 二次开发

- `server/`：Python 网关、证书、V4 Socket、波形编码和安全调度。
- `static/`：电脑控制台、手机游戏、共享规则与界面样式。
- `android/`：Android 原生传感器、安全 WebView、构建脚本和测试。
- `tests/`：协议、网页规则、仓库卫生、网络边界与输出安全回归测试。
- `coyote/`：官方协议资料索引，不包含运行代码或复制的上游文档。

安装开发依赖后执行 `./verify.command` 完成 Python、浏览器、Android、APK、服务启动和 Git 差异检查。贡献要求见 `CONTRIBUTING.md`，安全问题报告方式见 `SECURITY.md`。
