2. 信任步骤

iPhone：

  1. 用 Safari 下载描述文件。
  2. 进入“设置 > 通用 > VPN 与设备管理”安装描述文件。
  3. 进入“设置 > 通用 > 关于本机 > 证书信任设置”。
  4. 打开“GameBridge for Fun Local Root CA”的完全信任。

Android：

  1. 下载 `.cer` 文件。
  2. 在系统设置里搜索“CA 证书”或“从存储安装证书”。
  3. 安装为 Wi-Fi/VPN 或 CA 证书；不同品牌入口名称可能不同。

连接说明

  • 端口由服务启动时统一分配；遇到占用会自动向后寻找可用端口。
