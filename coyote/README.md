- V2/V3 波形协议：<https://github.com/dungeonlab-open/dglab-bluetooth-protocol/tree/main/coyote>

- Python Socket SDK：<https://github.com/dungeonlab-open/dglab-kit-python>

本地实现位于 `server/dglab_v4.py` 与 `server/coyote_waveforms.py`。修改编码前必须同时核对官方资料、现有回归测试和真实硬件结果；未知设备型号继续拒绝输出。
