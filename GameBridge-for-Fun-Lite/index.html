先判断是哪一层没有准备好

页面会保留当前阻止原因。没有 GPS/GNSS 的设备不能使用雷电极速，但不影响其他玩法。

无法连接

请使用 Android Chrome 或 Edge，并通过 HTTPS 打开。iOS Safari 和应用内浏览器没有 Web Bluetooth。

动作没有反应

重新检查动作权限并保持页面在前台；超过 1 秒没有新方向数据会安全停止。

速度一直无效

设备必须具有 GPS/GNSS，并允许精确定位。Lite 不保存或上传经纬度，只使用系统给出的速度。

长时间显示休息或间隔

这是玩法规则正在等待，不是页面卡死。急停和结束游戏始终可以立即作废任务。
