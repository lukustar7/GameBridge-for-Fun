# GameBridge for Fun Lite 使用说明

当前版本：`0.1.0-beta.1`

## 可用设备

Lite 需要同时满足以下条件：Android 设备、Chromium 系浏览器、蓝牙权限，以及受支持的 V2 或 V3 硬件。iOS/iPadOS Safari、应用内网页和仅支持传统蓝牙的浏览器不能直接连接。

雷电极速还要求手机或平板内置 GPS/GNSS。仅 Wi-Fi 且没有 GPS/GNSS 的设备不能使用该玩法，但不影响其他玩法。

## 首次使用

1. 打开 [Lite HTTPS 页面](https://lukustar7.github.io/GameBridge-for-Fun/GameBridge-for-Fun-Lite/)，浏览器菜单中可选择“添加到主屏幕”。
2. 打开硬件并保持在手机附近，点击“选择并连接设备”。
3. 在系统列表中选择设备；网页只会请求公开协议对应的蓝牙服务。
4. 选择输出通道、B 通道规则和波形，将网页 A/B 安全上限设为低值。
5. 阅读确认项并完成确认；连接或设置变化后需要重新确认。
6. 按实际接线点击“试 A”“试 B”或“试 A+B”。试电固定为强度 15、游戏默认波形和 1 秒时长，仍受对应网页上限约束。

Lite 不经过配套 App，无法读取或修改 App 内的强度限幅。网页 A/B 上限直接限制 Lite 发出的请求值；它是软件保护，不是设备固件保护，也不能替代设备电源或物理停止。

## 三个页面

- 设备与安全：检查浏览器能力、连接硬件、统一设置通道与波形、试电和急停。
- 选择玩法：查看四种玩法，调整当前玩法的全部参数并开始。
- 说明与排障：查看权限状态、离线版本和常见错误。

所有玩法共用“设备与安全”中的通道、B 通道比例、波形和 A/B 上限。玩法页面不重复提供这些选项。

每个玩法的设置按“基础”“节奏”“规则”或“堵车”分组，避免在手机上形成单个过长页面。当前字段、默认值和核心规则以电脑网关版为基准：

- 手抖挑战：安全半径或夹缝模式、开始与最高强度、倾斜灵敏度和出界等待。
- 摇骰子对决：每下强度与时长、间隔、豹子倍率、单局次数、摇晃灵敏度、对手难度和手动开关。
- 极速角子机：满槽与轻电、转动和休息、自动连转、压力变化、中奖率、三个数字 7 规则和结算后压力。
- 雷电极速：启动与满强度速度、行驶输出与休息、超速恢复、单局时长，以及默认关闭的堵车规则。

手抖挑战可以在开始前手动校准当前姿态。每个玩法都可以单独恢复默认值；从早期 Alpha 升级时，不兼容的旧玩法参数会自动恢复为已核对的默认值，全局接线和网页上限会保留但必须重新确认。

## 权限

- 蓝牙：必须由用户点击连接按钮后请求。拒绝后可再次点击连接按钮重试。
- 动作与方向：手抖挑战需要。iOS 当前不能连接硬件，权限状态仅作能力说明。
- 定位：雷电极速只读取浏览器给出的速度，不保存或上传经纬度。拒绝后可在浏览器站点设置中允许，再点击“重新检查权限”。
- 屏幕常亮：浏览器允许时在游戏运行期间申请；不支持时应关闭系统自动锁屏。
- 本机震动：仅作为开奖和警告反馈，不改变外接设备输出；不支持时不影响游戏判定。

浏览器不会向网页提供可靠的“永久拒绝”统一状态。页面会区分可用、待授权和不可用，并在操作失败时保留具体原因。

## 离线与更新

首次完整加载后，PWA 会缓存同版本的全部 HTML、CSS、JavaScript 和图标。启动时没有网络会继续使用缓存版本；蓝牙直连不依赖互联网。

检测到新版本时页面会提示。游戏输出期间不会切换版本；停止输出后才能确认更新并重新载入。

清除浏览器网站数据会同时删除设置和离线缓存，需要联网重新加载。

## 安全停止

页面顶部的“立即停止”始终可见。切换玩法、返回设置、页面进入后台、锁屏、蓝牙断开、传感器超时或代码异常都会废止旧任务并尝试发送 A/B 归零。

浏览器崩溃、手机断电、无线链路中断和硬件故障可能使归零指令无法到达。必须确保输出接收者或监护者能够直接操作硬件停止，不得把网页保护当作唯一措施。

## 常见问题

### 看不到蓝牙连接按钮

使用 Android Chrome 或 Edge，并确认页面地址为 HTTPS。应用内浏览器、无蓝牙设备和 iOS Safari 不受支持。

### 选择设备后提示型号不支持

Lite 只在发现公开 V2 或 V3 服务后发送数据，不会猜测未知协议。确认设备已开机、未被其他 App 占用；仍失败时不要反复试电。

### 动作玩法没有反应

先检查动作权限，再保持页面位于前台。方向数据超过 1 秒未更新时，Lite 会停止输出并显示传感器异常。

### 雷电极速无法开始

确认设备具有 GPS/GNSS、已允许精确定位并能在室外获得速度。没有可靠速度时不能绕过检查启动。
